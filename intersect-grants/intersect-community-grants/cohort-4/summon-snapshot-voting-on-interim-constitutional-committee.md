# Summon Snapshot Voting on Interim Constitutional Committee

Grantee will provide to Intersect the adoption of “Summon Snapshot Voting” for the upcoming Constitutional Committee election. The snapshot voting module consists of off-chain code that allows users to vote on proposals using cryptographic signatures via their own self-custodied wallets. This platform takes a snapshot of the Cardano blockchain at a particular block height and uses this data to verify the validity of the signatures. For this purpose, the grantee will create a custom voting page that allows any user with a Cardano wallet (including hardware wallet users) to log in, choose candidates in a rank- choiced system, and cast a ballot with voting power corresponding to their ADA holdings in the active stake snapshot of a particular epoch boundary.&#x20;

**Grant value: 158,000 ADA**

**Project complete.**

Milestone 1: Custom front end must allow for login from a wide selection of Cardano wallets including browser-based, mobile, and hardware options. Front end must allow for ranked-choice voting with ballot results collected to the voting database in a cryptographically secure manner.

Milestone 2: Ensure system performance for the Constitutional Committee election and work closely with Intersect staff to monitor and promote the election.

Milestone 3: Export results from the Constitutional Committee election in a way that is both human readable and cryptographically provable for use by Intersect staff.
