# Satya Ranjan

**Grant Value : 70,000 ADA**

## Scope:

* Update the Cardano Client Lib and Yaci to address new features available in the Conway Ledger Era

## Deliverables:

* Transaction serialization support to the Cardano Client Lib for Conway Ledger Era CDDL changes
* Update the Cardano Client Lib to expose simple transaction builder Java APIs for governance-related transaction
* Integrate Conway Ledger Era related CDDL changes to Yaci
* Upgrade Yaci’s current mini-protocol implementation for the Conway Ledger Era
