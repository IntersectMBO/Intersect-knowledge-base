# AdaStat

**Grant Value : 70,000 ADA**

## Scope:

* Update AdaStat to capture new governance data types available in the Conway Ledger Era

## Deliverables:

* Update AdaStat. Including but not limited to; (i) governance actions that are submitted, ratified, enacted, expired, or dropped (ii) votes cast by each DRep ID delegated stake to each DRep ID; (iii)votes cast by each constitutional committee member; (iv) votes cast by each SPO
