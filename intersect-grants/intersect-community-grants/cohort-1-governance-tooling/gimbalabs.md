# Gimbalabs

**Grant Value : 70,000 ADA**

## Scope:

* Update Dandelion for the Conway Ledger Era

## Deliverables:

* Dandelion server support, including but not limited to maintaining free Dandelion community service
* Including but not limited to;
  1. Rosetta API
  2. PostgREST API
  3. Submit API;
  4. Ogmios API;
  5. GraphQL API;
  6. Explorer API;
  7. Dandelion Alpha Network;
  8. Cardano Node Socket
* Delivery of proof of concept treasury tracking tool
* Update or create Dandelion API so that; Proof of concept treasury tool can be built upon

## Takeaways:

* Community grants are a helpful way to fun free infrastructure. This is important because it is hard for non-developers to understand infrastructure costs. We will continue to create examples to show to technical requirements of “decentralization” and to make sure that more people understand what’s happening “under the hood”.&#x20;
* Spending money is hard when you’re broke. Gimbalabs has lacked funding for so long that we’ve been slow to pay ourselves with these funds! We’re working to break free of this cycle now, and will use part of the funding to pay off some debt and balance the Gimbalabs ledger, even as we continue to fund innovative work.
