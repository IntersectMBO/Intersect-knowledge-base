# GERO

**Grant Value : 70,000 ADA**

### Scope:

* implement CIP-95 into the GeroWallet

### Deliverables:

Deliver UI updates to the GerWallet including, but is not limited to:

* Display the new governance transaction types (vote delegation, DRep registration, DRep retirement, vote, submit a governance action)
* Provide information for users that explains why reward accounts with stake credentials not delegated to a DRep will be blocked from withdrawing any rewards
